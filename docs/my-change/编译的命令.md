# 编译前端
  cd frontend && pnpm install && pnpm build && cd ..

# 1. 把前端产物复制到 embed 目录
  rm -rf internal/server/static/dist/assets
  mkdir -p internal/server/static/dist
  cp -r frontend/dist/* internal/server/static/dist/

  # 2. 交叉编译 Linux 二进制（你的服务器是 Linux）
  CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -tags=nomsgpack -ldflags "-s -w" -o axonhub ./cmd/axonhub

  因为你在 Windows 上，注意两点：

  - rm -rf 和 cp -r 是 bash 语法，如果你用的是 Git Bash 或 WSL 就没问题。如果用 PowerShell，对应命令是：
  Remove-Item -Recurse -Force internal\server\static\dist\assets
  Copy-Item -Recurse frontend\dist\* internal\server\static\dist\
  - 交叉编译那行在 Windows CMD/PowerShell 里需要分开设环境变量：
  $env:CGO_ENABLED=0; $env:GOOS="linux"; $env:GOARCH="amd64"
  go build -tags=nomsgpack -ldflags "-s -w" -o axonhub ./cmd/axonhub

  编译完成后项目根目录会生成一个 axonhub 文件（Linux 二进制），把它和 Dockerfile.prebuilt、docker-compose.yml、config.yml 一起传到服务器就行了。
